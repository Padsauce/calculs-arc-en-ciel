# Calculs Arc-en-ciel — journal des versions

Les fichiers numérotés sont des archives figées. Le lien partagé du jeu affiche toujours la dernière version.
Chaque version reçoit un numéro, qui suit celui de la page publiée.
Chaque version jouable est dans `versions/vN.html` (étiquette git `vN`). Le jeu en ligne est `index.html`.
